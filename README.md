# Сайт-портфолио — Кожухарёв Роман

**https://kozhuharyov.ru**

Персональный одностраничник разработчика игр: пишу код, учусь, собираю игры с командой.
Чистый HTML5 + CSS3 + Vanilla JS, без сборки, фреймворков и npm-зависимостей.
Единственная внешняя загрузка — шрифты Google Fonts (Golos Text, Oswald, IBM Plex Mono).

## Структура

```
index.html                    разметка, SEO-мета, SVG-иконки
assets/css/portfolio.css      вся вёрстка: постерный hero, проекты, адаптив и печать
assets/js/portfolio.js        прогрессивное улучшение: меню, фильтры, галерея, копирование
assets/img/portrait.webp      портрет для постера
assets/img/night-walk.webp    личные кадры для секции «Вне кода»
assets/img/car-front.webp     личные кадры для секции «Вне кода»
assets/img/og-preview.png     превью 1200x630 для мессенджеров
assets/img/rk-mark.svg        монограмма-иконка
tools/                        только для разработки, на прод не влияет
```

## Локальный запуск

Достаточно открыть `index.html` — сайт работает и по `file://`. Если нужен http-сервер:

```powershell
python -m http.server 8080     # затем http://localhost:8080
```

Параметр `?instant=1` в старых сборках пропускал прелоадер; в текущей версии прелоадера
нет — страница сразу доступна, скролл не блокируется.

## Как устроено

**Композиция.** Светлая «бумажная» основа, кобальтовый акцент и крупная типографика.
В hero — постер: портрет в оттенках серого, синий блок, синяя рамка-фокус и вынос
цветного фрагмента. При наведении цветной фрагмент раскрывается на весь портрет.

**Проекты.** Для каждого из четырёх репозиториев нарисована своя схема-иллюстрация
(интерфейс чата, схема парсинга, «лист заявки», список задач) — вместо выдуманных
скриншотов. Фильтры «Все / Боты / Инструменты» реально скрывают карточки.

**Секции.** Обо мне, проекты, навыки, командная игра (синяя полоса во всю ширину),
«Вне кода» с личными фотографиями и галереей, контакты с копированием email.

**Навигация.** Вверху — обычное меню; на узких экранах — кнопка с выпадающим списком.
При прокрутке появляется стеклянный док с быстрыми переходами.

## Производительность и доступность

- Никаких постоянных циклов анимации: прокрутка считается в одном `requestAnimationFrame`,
  частиц и canvas больше нет.
- Фотографии пережаты в WebP (53–90 КБ), из EXIF удалены координаты съёмки.
- `prefers-reduced-motion: reduce` отключает анимации, поворот карточек и раскрытие портрета.
- Галерея использует нативный `<dialog>` — браузер сам держит фокус и закрывает по Escape.
- Есть skip-link, `:focus-visible`, `aria-expanded` у меню, `aria-live` у счётчика проектов
  и статуса копирования, `alt` у всех фотографий. Без JS открывается весь контент.
- Печать (`Ctrl+P`) оформлена отдельными правилами: скрываются док, меню и фильтры,
  показываются все проекты.
